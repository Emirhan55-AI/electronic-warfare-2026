# Zynq PS

Bu dizin Zynq ARM/PetaLinux üzerinde çalışması hedeflenen, PC'yi algoritma motoru yapmayan PS sözleşmelerini taşır. `phase06i/` içindeki C ABI tanımı ve decoder kaynakları host veya ARM compiler ile derlenebilir biçimde hazırlanmıştır; mevcut checkpoint'te uygun compiler/sysroot bulunmadığı için derlenmiş veya ZedBoard üzerinde çalıştırılmış sayılmaz.
